# M5 批量生图（卡片组合批量生成）

> 依据：与用户 2026-08-08 共识；请求构造沿用 `docs/m4-generation-request.md` 与 ANR `src/generate_images.py`。

## 1. 核心规则（已与用户确认）

- 组合维度固定为工作区正面分区中的「角色 / 动作 / 画师串」三个系统分区；分区内有内容的自定义分区可二选一：
  - **全局共享**：内容进入每张图的全局正面基础，不增加张数（默认）；
  - **作为维度**：参与组合，总张数乘以该维度卡片系数之和。
- 卡片归属只看所在分区，与卡片自身分类无关（质量卡放进画师串分区即视为画师串维度的一张卡）。
- 组合分区内出现散装提示词块（非卡片）时**禁止开始**：前端弹窗引导，并提供「一键移到提示词工作台」按钮（移入后作为全局正面基础）。
- 提示词工作台允许散装块，全部作为全局正面基础；为空也允许开始（提示词由组合卡片拼出）。
- 负面区全部内容固定传入每张图（沿用现有逻辑：再叠加 UC 预设词）。
- 系数为**每张卡片**的独立数值（≥ 1，整数）；分区级「统一系数」是批量设置快捷入口。
  - 总张数 = 各维度（卡片系数之和）的连乘；等价于逐组合枚举，每个组合重复「组合内各卡系数之积」次。
  - 例：角色 2 张 ×1、动作 4 张 ×10、画师串 1 张 ×1 → 2 × 40 × 1 = 80 张，每组合 10 张。
- 串行逐张生成（与 ANR 一致），不做并发；单次请求 1 张。
- 请求节流（与 ANR `sleep_for_cool` 一致）：每张之间随机等待 3~5 秒；网络类错误（SSL/HTTP/超时）自动重试，最多 2 次，每次重试前随机等待 6~10 秒，重试仍失败才记录失败并暂停等待用户继续，避免连续快速请求触发 NovelAI 限流。
- 停止条件：剩余点数低于阈值（默认当前点数 −1000，可快速 −100 / −1000 或手动修改，**开始时固定**）；免费档（步数 ≤ 28 且分辨率为免费档）不检查点数；无最大张数上限，开始前向用户详细告知参数/张数/点数限制/预计时间。
- 参数 = 开始瞬间的参数面板快照（含 Vibe），运行期间锁定；下一次批量可重新修改。
- 中断（用户暂停 / 网络中断 / 进程重启 / 点数自动停止）后，断点记录持久化，可「继续上次未完成的任务」；只有用户确认「结束任务」才清理断点记录文件。
- 每张图完成后在右侧预览区实时显示最新图；任务记录按图（组合 + 种子）落盘，保证从精确断点续跑、不重复已完成组合。

## 2. 后端接口

### `POST /api/generate/batch`

创建并启动批量任务。请求体：

```json
{
  "base_positive": "<质量:环境card睡衣打光>",
  "negative": "<负面:万用负面>,<负面:去除小人>",
  "dimensions": [
    {
      "name": "角色",
      "cards": [
        { "category": "角色", "name": "伊吹ibuki", "coefficient": 1 }
      ]
    }
  ],
  "params": { "...": "生成参数快照（含 vibes）" },
  "stop_anlas": 7935
}
```

校验：token 已配置、每维度至少 1 张卡、系数 ≥ 1、无未结束任务；非免费时当前点数须高于停止阈值。返回 `BatchRun` 视图。

### `GET /api/generate/batch`

返回 `{ "active": bool, "run": BatchRun | null }`。进程重启后遗留的 `running` 记录自动标记为 `paused`（断点保留）。

### `POST /api/generate/batch/pause` / `resume` / `end`

- `pause`：仅运行中可调用；当前图片完成后停下，记录保留。
- `resume`：从断点继续（非免费时先校验点数仍高于阈值）。
- `end`：确认结束；停止任务并删除断点记录文件。

### `BatchRun` 关键字段

`id / status（running|paused|stopped|completed）/ stop_reason / total / done / failed / remaining / current_combo / last_image{path,name,seed} / anlas / estimate_sec / eta_sec / free / stop_anlas / dimensions / base_positive / negative / params（摘要）`。

## 3. 实现位置

- 后端：`backend/app/batch.py`（组合枚举、串行 worker、断点记录 `batch_runs/active.json`，已 gitignore）；路由在 `backend/app/main.py`；免费判定 `novelai.is_free_params`。
- 前端：`frontend/src/components/BatchPanel.tsx`（配置/进度/弹窗）、`frontend/src/store/batch.ts`（运行状态 + 本地配置持久化）、`GenerationPanel.tsx`（参数锁定遮罩、单张按钮禁用、最新图实时预览）。

## 4. 已知说明

- 单张失败（校验类）记录为 failed 并继续；网络类失败自动暂停等待恢复，继续时重跑未完成项。
- 失败后重试成功的条目会清除旧错误信息；重试失败前已保存的图不会重复生成（断点按图记录）。
- 结束任务时若正在生成当前图，该图会照常保存入图库（记录不再写盘）。

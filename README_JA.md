## 概要

PromptCard Studioは、ローカル優先で動作するNovelAIプロンプト管理ツールです。プロンプトを再利用可能な「カード」として整理し、ワークスペース上で素早く組み合わせ、分類、並べ替えできます。画像ライブラリやVibe参照画像の管理、カードの組み合わせによる一括生成、公開前の画像処理（アップスケール・ノイズ除去／自動モザイク／メタデータ削除／一括リネーム）にも対応しています。ダウンロードして展開すれば使用でき、すべてのデータは自分のPC内に保存されます。

v1.2.0で追加された「画風探索」モジュールでは、ArtistPoolからArtist Stringの候補を生成し、仕分け、交叉、変異、家族単位の戻し交配を重ねながら、自分だけの画風へ段階的に収束させられます。機能デモ：https://www.bilibili.com/video/BV1ru8Y6gE3L/

> **対応プラットフォーム：** 現在、主にテストされ正式にサポートされているのはWindows 10/11 64-bitです。macOS/Linux向けの起動スクリプトも残されていますが、実験的サポートのため十分な検証は行われておらず、すべての機能や今後の継続的な互換性は保証されません。

## クイックスタート

1. https://www.python.org/downloads/ からPython 3.10以降をインストールします。インストール時に **Add Python to PATH** を選択してください。標準版CPythonを使用してください。free-threading／GILなしの実験的ビルドには現在対応していません。
2. 本プロジェクトをダウンロードして展開します。
3. Windowsでは **run.bat** をダブルクリックします。macOS/Linuxでは **run.sh** を試すことができます（実験的サポート）。初回起動時に実行環境の作成と依存関係のインストールを行い、サービスを起動してブラウザを開きます。2回目以降も同じスクリプトを使用してください。
4. サービスを終了するには、アプリ内の **設定 → ローカルサービスを終了**（中国語UI：`设置 → 关闭本地服务`）を使用します。

### アップグレードとデータ移行

アプリ起動後、バックグラウンドでGitHubの正式リリースを確認します。**設定 → 更新と移行**（`设置 → 更新与迁移`）から手動で確認することもできます。新しいバージョンが見つかったら、更新内容を確認して新しいポータブル統合パッケージをダウンロードしてください。アプリが現在のプロジェクトを自動的に上書きしたり、旧ディレクトリを削除したりすることはありません。

新しいプロジェクトを起動した後、**設定 → 更新と移行 → 旧プロジェクトフォルダーを選択**（`设置 → 更新与迁移 → 选择旧项目文件夹`）から旧プロジェクトのディレクトリを選択します。移行ツールは、カード、画像ライブラリ、Vibe、設定、辞書のカスタム内容、背景画像、エンジンのランタイム、プラグインのランタイムデータをコピーします。プログラムコード、依存関係、ビルド成果物は移行されません。同名ファイルは先に新プロジェクトの `.migration-backups/<timestamp>/` へバックアップされ、設定画面に保存先が表示されます。移行後は **プロジェクトをクイック再起動**（`快速重启项目`）して内容を反映してください。新しいプロジェクトのデータを確認してから、バックアップと旧ディレクトリを手動で削除できます。

起動スクリプト：

- `run.bat`（Windows）／`run.sh`（macOS/Linux、実験的サポート）が唯一の起動入口です。環境準備、依存関係のインストール、サービス起動を自動で行い、使用中のポートがある場合は別のポートを選択します。

ヒント：

- 環境のセットアップで問題が発生した場合は、Releasesページにある展開後すぐ使えるポータブル統合パッケージをお試しください。
- ソース版の初回起動では依存関係のインストールにインターネット接続が必要です。ビルド済みフロントエンドが同梱されているため、Node.jsは不要です。
- ポート14419が使用中の場合は、自動的に別のポートへ切り替わります。
- free-threading（GILなし）版Pythonが検出された場合、標準版CPythonを使って実行環境を自動的に再構築します。
- NovelAIで画像を生成する前に、**設定**（`设置`）でNovelAI Tokenを入力してください。Tokenはローカルにのみ保存されます。

## 使い方

以下では主要モジュールごとに操作方法を説明します。必要に応じて、日本語名の後ろに中国語UI上の表記を併記しています。

### プロンプトワークスペース

プロンプトワークスペース（`提示词工作台`）は中心となる編集エリアです。**メインプロンプト／キャラクター／アクション／Artist String／末尾のネガティブプロンプト**に分かれたブロック式レイアウトを採用しています。各セクションにはカード参照または自由入力のテキストブロックを配置でき、最終的に順番どおり1つのプロンプトへ結合されます。

主な機能：

- **カード参照＋自由入力：** Promptカードライブラリからカードをクリックまたはドラッグして参照を作成できます。任意のテキストを直接入力・貼り付けることもできます。
- **ドラッグによる並べ替え：** ブロックの順序を変更し、キャラクター、アクション、Artist Stringの出力順を調整できます。
- **元に戻す／やり直す：** 編集操作をいつでも取り消し、復元できます。
- **プロンプト分割（中国語ラベルの自動付与）：** 長いプロンプトをカテゴリ別のブロックに分割し、ローカル辞書を使って認識したタグへ中国語ラベルを付けます。
- **中国語翻訳：** 英語タグを自動で中国語に注釈・翻訳し、意味を確認しやすくします。
- **合成カード：** 現在のワークスペース内容を新しいカードとして保存します。
- **複数選択の移動／プロンプト結合：** 複数のブロックをまとめて指定セクションへ移動または結合します。
- **ポジティブ／ネガティブ切り替え：** ポジティブプロンプトとネガティブプロンプトを別々に編集し、ワンクリックで切り替えます。

操作手順：

1. **プロンプトワークスペース**（`提示词工作台`）を開き、左下の **＋テキストブロック**（`+ 文本块`）をクリックするか、カードライブラリからカードをドラッグします。
2. NovelAIのプロンプト全体を貼り付けて **分割**（`分块`）をクリックします。内容が各セクションへ分割され、中国語ラベルが表示されます（図1-1）。
3. ブロックをドラッグして順番を調整し、不要な部分を削除または結合します。
4. 編集が終わったら **合成カード**（`合成卡片`）をクリックし、再利用できるようカードライブラリへ保存します。

![図1-1 分割後に自動ラベルが付いたプロンプトワークスペース](images/1-1.png)

### Promptカードライブラリ

Promptカードライブラリ（`Prompt 卡包`）は、カードをカテゴリ別に管理する保管場所です。**キャラクター／アクション／Artist String／ネガティブ／品質／シーン／表情／服装**などのカテゴリを内蔵し、ピン留め、検索、XLSXテンプレートによる一括インポートに対応しています。

主な機能：

- **カテゴリ管理：** カテゴリの作成・名前変更、カードのピン留め、カテゴリ色や表示順の調整ができます。
- **一括インポート：** 内蔵の `卡片导入模板.xlsx` に「カテゴリ／名前／プロンプト／画像（任意）」を入力して一括で取り込めます。同名カードには自動で接尾辞が付きます。
- **ZIPエクスポート：** 選択したカードをZIPにまとめて共有またはバックアップできます。
- **カード画像：** 各カードに画像を設定し、視覚的に判別しやすくできます。

操作手順：

1. **Promptカードライブラリ**（`Prompt 卡包`）を開き、左側でカテゴリを選択または作成します。
2. **新規カード**（`新建卡片`）をクリックし、名前とプロンプトを入力します。必要に応じて画像を付けて保存すると、カードが一覧に表示されます（図2-2）。
3. 一括インポートする場合は **一括インポート**（`批量导入`）からテンプレートをダウンロードし、各列を入力してアップロードします。
4. カードをクリックするとワークスペースへ追加できます。よく使うカードはピン留めできます。

### プロンプト辞書

プロンプト辞書（`提示词词典`）はローカルで動作する中国語注釈ツールです。**Danbooruタグ**をカテゴリ分けし、種類ごとに色を付け、中国語の注釈を表示します。ワークスペースでプロンプトを分割・翻訳するときに使用されます。

主な機能：

- **自動色分け：** キャラクター、アクション、Artist String、品質、ネガティブなど、カテゴリごとに異なる色で表示します。
- **中国語注釈：** タグにカーソルを合わせると中国語の意味を確認できます。
- **未登録語の手動追加：** 辞書にないタグを手動登録できます。保存後は自動注釈の対象になります。

操作手順：

1. **プロンプトワークスペース**へプロンプトを貼り付け、**分割**（`分块`）をクリックします。辞書がタグを認識して中国語ラベルを付けます（図1-1）。
2. 分割後にプロンプトブロックを編集し、ブロックまたはその中のタグを辞書へ追加できます（図3-2）。
3. 未登録のタグは、ブロックの編集中に直接追加して中国語注釈を入力できます。

![図3-2 プロンプトブロックを編集して辞書へ追加](images/3-2编辑提示词块并且可添加进词典.png)

### NovelAI画像生成

ワークスペースでプロンプトを組み立てた後、NovelAIを直接呼び出して画像を1枚生成できます。

主な機能：

- **詳細なパラメータ：** モデル／解像度／ステップ数／サンプラー／ネガティブプリセット／品質タグ／Variety／Vibe参照／複数キャラクターを設定できます。
- **パラメータの自動記憶：** 前回の設定が保持されるため、毎回入力し直す必要がありません。
- **結果をライブラリへ保存：** 生成画像を画像ライブラリへ直接保存し、プロンプトやシードなどのPNG情報も保持します。

操作手順：

1. **設定**（`设置`）でNovelAI Tokenを入力します。Tokenはローカルにのみ保存されます。
2. ワークスペースでプロンプトを組み立て、必要に応じてVibe参照画像を選択します。
3. 画像生成パネルを開き、モデル、解像度、ステップ数、サンプラーなどを設定します（図4-1）。
4. **生成**（`生成`）をクリックします。完了後は結果のプレビュー、再試行、画像ライブラリへの保存ができます（図4-2）。

### 一括生成

**キャラクター × アクション × Artist String**などの組み合わせを自動で列挙し、多数の候補画像をまとめて生成できます。

主な機能：

- **組み合わせの列挙：** キャラクター、アクション、Artist Stringの3軸を自動で組み合わせます。任意のカスタム軸も追加できます。
- **カードごとの係数：** 各カードの係数を設定し、組み合わせに参加する回数を調整できます。
- **逐次生成：** キューを1枚ずつ処理し、同時リクエストによる制限を避けます。
- **残ポイント停止しきい値：** 残りポイントが設定値を下回ると自動で停止します。
- **途中再開：** 中断した位置から再開し、完了済みの画像を重複生成しません。

操作手順：

1. **一括生成**（`批量生成`）を開き、使用するキャラクター、アクション、Artist Stringを選択します（図5-1）。
2. カード係数、停止しきい値、生成パラメータを設定します。
3. **開始**（`开始`）をクリックして順番に生成します。いつでも一時停止でき、再度開始するとチェックポイントから続行します。
4. 結果は画像ライブラリへ追加され、日付別に確認できます。

![図5-1 一括生成の組み合わせ設定](images/5-1.png)

### 画風探索

画風探索（`画风探索`）では、同じプロンプトと生成パラメータのもとで、ArtistPoolから異なるArtist Stringを組み立てます。基礎探索で候補の幅を広げ、Treasureに選んだ結果を親として交叉、変異、家族単位の戻し交配を行い、目標とする画風へ段階的に収束させます。

主な機能：

- **独立した探索タスク：** タスクごとにプロンプト、生成パラメータ、ArtistPool、候補画像、系譜を保存し、一時停止・再開できます。
- **基礎探索：** ArtistPool内のアーティストIDをランダムに組み合わせ、指定した重みでArtist String候補を生成します。
- **探索ギャラリー：** 結果をTreasure／Special／Rejectへ仕分けます。Treasureは深度探索の親として使用できます。
- **深度探索：** 選択した親を中心に交叉とランダム変異を行います。任意で好みの順位付けやカスタムArtist Stringも追加できます。
- **家族と審美ブランチ：** 通常の親セットごとに独立した家族を作成します。選んだ優秀な子個体を家族の第1世代の親と戻し交配し、特定の方向へ世代を重ねて収束させます。
- **同一世代へのラウンド追加：** サンプルが不足している場合、同じ親関係を使って同世代の候補を追加生成できます。
- **結果の再利用：** 候補を拡大表示し、Artist Stringカードを作成したり、通常の画像ライブラリへコピーしたりできます。

#### 基礎探索

1. **画風探索**（`画风探索`）を開き、探索タスクを作成または選択します。左側でArtistPoolを選ぶか、TXTファイルをインポートします。ポジティブ／ネガティブプロンプトはワークスペースから取り込むことも、このページで個別に編集することもできます（図10-1）。
2. モデル、画像サイズ、サンプラー、アーティスト数、重み分布などを設定します。NovelAI V5モデルでは、重みの **最頻値**（中国語UI：`众数`）をまず `0.4` 前後に設定し、結果に応じて調整する方法を推奨します（図10-2）。
3. 基礎探索ラウンドを作成して **生成開始**（`开始生成`）をクリックします。結果は現在のタスクの候補欄に表示され、すべての生成が終わる前でも完了済み画像に印を付けられます（図10-3）。
4. 候補をクリックすると拡大してArtist Stringを確認できます。そのままArtist Stringカードを作成し、Promptカードライブラリへ保存できます（図10-4）。

#### 仕分けと探索ギャラリー

基礎探索ラウンドの生成後、正式な仕分け画面を開き、画像をタスク専用の3つのギャラリーへ分類します（図10-5）。

- **Treasure：** 気に入って、さらに進化させたい結果です。深度探索の親として使用できます。
- **Special：** 独特で保存する価値はありますが、今回の深度探索では親として使用しない結果です。
- **Reject：** 今回の目標に合わない結果です。

![図10-5 探索結果をTreasure、Special、Rejectへ仕分け](images/10-5.png)

#### 深度探索

1. 現在のタスクのTreasureから画像を選び、通常の親セットを作成します。カスタムArtist Stringを追加することもできます。親のArtist Stringを交叉・ランダム変異させて新しい候補を作ります（図10-6）。
2. 1ラウンド生成した後、目標に合う子個体が含まれる画像スタックの右側で **新規ブランチ**（`新建分支`）をクリックします。優秀な子個体を選び、その審美方向に名前を付けます。選択した子個体を家族の第1世代の親と戻し交配し、以降の世代でさらに収束させられます（図10-7）。
3. 同世代のサンプルが少ない、または理想的な結果がまだない場合は、**ラウンドを追加**（`新增一轮`）をクリックします。同じ親関係を再利用して、同世代の候補グループを追加します（図10-8）。
4. 画像スタックをクリックすると、そのラウンドとタスク全体の進捗、およびスタック内の全候補を下部で確認できます（図10-9）。候補をクリックして拡大し、Artist Stringカードを作成したり、通常の画像ライブラリへコピーしたりできます（図10-10）。

### 画像ライブラリ

画像ライブラリ（`图片库`）では、ローカルで生成・インポートした画像を管理し、NovelAIのPNG情報を活用できます。

主な機能：

- **Masonry表示＋日付グループ：** 日付ごとに整理された画像を、スクロールしながら読み込んで閲覧できます。
- **仕分けモード：** Treasure／Fine／Reject／お気に入りに分類して素早く整理できます。
- **PNG情報の復元：** 画像内のプロンプト、パラメータ、シードを読み取り、ワンクリックでワークスペースへ復元します（図6-2）。
- **素早いインポート／移動／削除：** ローカル画像をドラッグして取り込み、まとめて移動・削除できます。
- **カテゴリカバー：** 任意の画像をカテゴリのカバーとして設定できます。

操作手順：

1. 画像を画像ライブラリへドラッグするか、**インポート**（`导入`）からローカルファイルを選択します。
2. 上部の仕分けモードを使い、良い画像をTreasure、不要な画像をRejectにします。ライブラリのホーム画面は図0-2です。
3. 画像を再現したい場合は選択して **ワークスペースへ復元**（`还原到工作区`）をクリックします。プロンプトとパラメータが自動入力されます（図6-2）。
4. コンテキストメニューまたは操作メニューから、画像の移動、削除、カバー設定ができます。これらの操作には専用スクリーンショットはありません。

### 公開前処理

公開前処理（`发布处理`）は、SNSなどへ投稿する前に選択した画像をまとめて整える独立したワークフローです。画像をステージング領域に入れ、固定順の処理ノードを通してから出力します。

主な機能：

- **独立したステージング領域：** 画像ライブラリで画像を選択し、**クイック選択 → 公開前処理**（`快捷选取 → 发布处理`）を実行します。ハードリンクにより元画像を変更せず、ほぼ瞬時にステージングへ複製します。公開画面ではプレビュー、削除、全消去、追加ができます。
- **固定されたノード順：** アップスケール・ノイズ除去 → 自動モザイク（任意）→ 元メタデータの復元 → メタデータ削除 → 一括リネーム。
- **アップスケール・ノイズ除去：** ncnn-Vulkan版Real-ESRGAN（検証付き・レジューム対応の自動ダウンロード）と、ローカルパスで接続するwaifu2x-caffeに対応します。
- **自動モザイク：** 任意のプラグインです。有効にすると処理ノードが現れ、対象部位（陰茎／外陰部／乳房、中国語UI：`欧金金 / 欧芒果 / 欧派派`）と処理方法（ピクセル化／ぼかし／線／単色）を選択できます。対象が検出されなかった画像は自動的にスキップされます。
- **元メタデータの復元：** アップスケール後に元画像のプロンプトとパラメータを書き戻し、画質を上げても生成情報を保持します。
- **メタデータ削除：** 残りのブロックをnull値で上書きし、NovelAIなどの読み取りツールから空として見えるようにします。JPEGではEXIF/XMPも削除します。
- **一括リネーム：** 任意の日付、任意のカスタム文字列、6桁のランダム数字を組み合わせます。3つの部分はドラッグで並べ替えでき、ファイル名をリアルタイムで確認できます。
- **出力：** 結果を個別の `outputs/<timestamp>-<random>/` ディレクトリへ出力し、完了後にワンクリックで開けます。

操作手順：

1. 画像ライブラリで公開する画像を選び、**クイック選択 → 公開前処理**（`快捷选取 → 发布处理`）を実行してステージングへ追加します（図7-1）。
2. 公開画面でステージング内容を確認し、プレビュー、削除、画像の追加を行います。
3. 自動モザイクを使う場合は、任意プラグイン欄の **ダウンロードして有効化**（`下载并启用`）をクリックし、約42.5 MBの検出モデルのダウンロードを確認します。その後、**自動モザイク**（`自动打码`）ノードが表示されます。
4. ノードを順番に設定します。任意のアップスケールエンジンとパラメータを選び、自動モザイクの対象と方式、元メタデータの復元、メタデータ削除を必要に応じて有効にします。これらの設定には専用スクリーンショットはありません。
5. リネーム規則を設定し、右側のリアルタイムプレビューでファイル名を確認します（図7-3）。
6. **処理開始**（`开始处理`）をクリックします。完了後、**出力フォルダーを開く**（`打开输出文件`）から結果を確認します（図7-4）。

### Vibe管理

VibeはNovelAIの参照画像機能です。本プロジェクトにはVibeライブラリがあり、画像生成や一括生成の参照として使用できます。

### 設定

設定画面（`设置`）では、外観、保存先、アカウント情報、機能スイッチをまとめて管理します。

主な機能：

- **テーマと背景：** ダーク／ライトテーマ、カードのガラス効果の強度、背景ぼかし、内蔵背景の切り替え。
- **画像ライブラリの保存先：** 初期設定ではプロジェクト内の `library/` を使用し、任意の絶対パスへ変更できます。

## 機能一覧

- **プロンプトワークスペース：** メインプロンプト／キャラクター／アクション／Artist String／末尾のネガティブプロンプトに分かれたブロック式ワークスペースです。カード参照、自由入力、ドラッグ並べ替え、元に戻す／やり直す、中国語ラベル付きプロンプト分割、合成カード、複数選択の移動、プロンプト結合、ポジティブ／ネガティブ切り替えに対応します。
- **Promptカードライブラリ：** カテゴリ別のカード管理、ピン留め、XLSX一括インポート（カテゴリ／名前／プロンプト／任意画像、同名には自動接尾辞）、ZIPエクスポートに対応します。
- **プロンプト辞書：** Danbooruタグのカテゴリに応じた色分けと中国語注釈をローカルで提供し、未登録語を手動追加できます。
- **NovelAI画像生成：** モデル／解像度／ステップ数／サンプラー／ネガティブプリセット／品質タグ／Variety／Vibe参照／複数キャラクターを設定して1枚ずつ生成し、パラメータを記憶します。
- **一括生成：** キャラクター、アクション、Artist String、任意のカスタム軸を組み合わせ、カード係数、逐次生成、残ポイント停止しきい値、途中再開を利用できます。
- **画風探索：** ArtistPoolからArtist Stringを作成し、Treasure／Special／Rejectの仕分け、深度交叉と変異、独立した家族、審美ブランチ、同世代の追加ラウンドを通して画風を収束させます。結果はArtist Stringカードまたは通常の画像ライブラリへ保存できます。
- **画像ライブラリ：** Masonry表示、日付グループ、Treasure／Fine／Reject／お気に入りの仕分け、PNG情報の復元、素早いインポート／移動／削除、カテゴリカバーに対応します。
- **公開前処理：** 選択画像を独立したステージング領域へ送り、アップスケール・ノイズ除去 → 任意の自動モザイク → 元メタデータの復元 → メタデータ削除 → 並べ替え可能な一括リネームの順で処理し、`outputs/` の個別フォルダーへ出力します。
- **Vibe管理：** Vibe参照ファイルのインポート、名前変更、プレビュー。
- **設定：** テーマ、背景、画像ライブラリの保存先、NovelAI Token、視覚効果、複数キャラクター、中国語翻訳、自動注釈など。

## プライバシーとセキュリティ

- アプリは完全にローカルで動作します。ユーザーが明示的に開始したNovelAI画像生成リクエストを除き、外部サービスへデータを送信しません。アップスケールエンジンは選択時にのみ公式またはミラー配布元からダウンロードします。自動モザイクの検出モデルも有効化を確認したときに一度だけダウンロードされ、処理はすべてローカルで行われます。画像がアップロードされることはありません。
- NovelAI Tokenはローカル設定ファイルにのみ保存され、APIレスポンス、ログ、コミットには含まれません。設定ファイルとすべてのユーザーデータディレクトリは `.gitignore` の対象であり、リポジトリには入りません。
- Token、ローカル設定、ユーザーデータディレクトリを公開リポジトリへコミットしないでください。
